# Data provenance and licensing

Every dataset touched by this repo, what it is licensed for, and how it is used here.

## 1. Amazon Reviews 2023 — Automotive product metadata

| | |
|---|---|
| **Source** | https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023 |
| **Config used** | `raw_meta_Automotive` (~2M product listings) |
| **Maintainer** | McAuley Lab, UC San Diego |
| **Terms** | Released for **research use with citation**. Not licensed for re-hosting. |
| **How used here** | Primary corpus. Downloaded at build time, cached to `data/raw/`. |
| **Redistributed?** | **No.** `data/` is gitignored. `load_documents()` regenerates it. |

Reproducibility without redistribution works because the sample is deterministic: rows are
selected by a stable hash of each product's ASIN seeded with `data.seed`, not by shuffling. The
same `n_docs` yields the same documents on any machine, in any `datasets` version, regardless of
streaming order.

`corpus_checksum()` hashes the `(doc_id, text)` pairs, and that checksum is written into every
`results/*/metrics.json`. A reviewer runs the same config, compares checksums, and knows byte-for-byte
whether they are looking at the same corpus before comparing any metric.

**Required citation:**

```bibtex
@article{hou2024bridging,
  title={Bridging Language and Items for Retrieval and Recommendation},
  author={Hou, Yupeng and Li, Jiacheng and He, Zhankui and Yan, An and
          Chen, Xiusi and McAuley, Julian},
  journal={arXiv preprint arXiv:2403.03952},
  year={2024}
}
```

## 4. Deliberately not used

**Retailer and manufacturer catalog PDFs.** Publicly downloadable is not the same as licensed for
reuse. Those catalogs are copyrighted, and site terms typically restrict copying and
redistribution regardless of whether a login was required. Since the goal of this project is a
benchmark anyone can rerun and verify, including a corpus that cannot legally be regenerated by a
third party would defeat the point.

The factual layer — part number, fitment, dimensions — is not itself copyrightable, so a future
fitment dataset built from openly licensed sources is on solid ground. The *expression* (page
layout, descriptions, images, curated arrangement) is not, and none of it appears here.

**Kaggle auto-parts datasets.** Excluded for now because license fields are inconsistent and many
are marked "unknown". Any that are added later must be CC0 or CC-BY and listed in this file first.

## 5. Planned addition — ACES/PIES sample data

The Auto Care Association publishes free sample ACES (fitment) and PIES (product information)
files through its Digital Hub. These are the real industry interchange standards and would give
this benchmark genuine domain credibility rather than generic ecommerce retrieval.

Constraint to respect: the underlying reference databases (VCdb, PCdb, PAdb) require a paid
subscription. Only the openly published sample files are usable here, and that limitation should
be stated plainly in any writeup rather than glossed over.

## The habit worth keeping

Publicly downloadable is not the green light — the **license or terms** are. Before any dataset
enters this repo it gets a row in this file: source URL, license, how it is used, and whether it
is redistributed. A reader can audit the entire data supply chain from this one page, which is
cheap to maintain and disproportionately raises trust in the results.

*This file documents licensing diligence, not legal advice.*
